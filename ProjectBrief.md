# Daybook - Project Brief

**What problem does it solve?**
Students often make a plan one day and change it the next, so they never stick to a fixed routine. I built Daybook so users can lock their routine for a set period (7 days) and then evaluate how well they followed it.

**Who is it for?**
Students and working professionals who have tasks to complete under deadlines.

**Why did you choose this idea?**
I faced this problem myself and wanted a simple way to track my progress.
